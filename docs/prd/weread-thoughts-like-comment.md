## 1. 背景与问题

阅读器已能点击热门划线查看他人想法，并展示点赞数，但赞是死的，也不能在看书时写下自己的想法。点赞和点评无法同步到微信读书 App。

## 2. 目标

1. 热门想法可点赞、可取消赞，数据与微信读书 App 一致。
2. 看书时能点评：选中正文写想法，或在热门划线的想法列表底部写想法。
3. 写想法使用官方可见范围（默认「屏蔽好友」），同一账号在 App 里可查。

## 3. 用户故事

- 作为读者，我希望给一段热门想法点赞，并在手机 App 里看到这个赞。
- 作为读者，我希望选中一段正文或对着热门划线写下想法，并在 App 的「我的想法」里找到它。
- 作为不想被微信读书好友刷到的用户，我希望发出去默认是官方的「屏蔽好友」，发送前也能改成公开 / 关注 / 私密。

## 4. 方案（面向用户）

### 4.1 点热门划线

沿用现有 Popover：标题「想法 · n」、作者、正文（相对头像缩进）、右下可点赞。点划线只出列表；点「写想法」后才出现输入框与官方可见范围。列表条目不展示可见范围标签。控件色跟 VS Code 主题（`button.background` 等），不用 antd 默认蓝。

### 4.2 选中正文

选中非空文本后出现「写想法」。`range` 按与 `.xhtml-content` 相同的展示 HTML（strip / TXT 包 `<p>`，注入热门划线 span 之前）计算文本偏移，再映射回未 strip 原文下标，与官方热门划线同一套坐标；算不出则不发送。官方划选写想法只打 `/web/review/add`（`type=1`，自带 `range`），**不**另打划线接口；正文划线由阅读器按官方三路 range 合并后画出。

### 4.3 可见范围

写想法时选择官方四档：公开 / 关注 / 屏蔽好友 / 私密。默认屏蔽好友。输入区旁显示当前将要发出的档。「屏蔽好友」是官方能力（仅未关注你的人可见），不是插件自造。

### 4.4 同步

点赞与发表必须打到微信读书官方接口。插件成功后，同一账号在 App 可查。

## 5. 非目标

整本书评、改/删已有想法、只划线不写想法、列表可见范围徽章、新依赖。详见设计文档。写想法走 `/web/review/add`，划线来自想法自带 `range`。

## 6. 验收标准

见设计文档「失败与验收」。插件点赞、发表后须在微信读书 App 能查到，行为与官方一致。
