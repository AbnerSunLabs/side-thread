# Spec

## Feature Description

在微信读书阅读器里，用户可以查看热门划线下的想法并点赞，也可以在看书时对选中原文或当前热门划线发表想法。点赞和发表都走微信读书官方接口、官方可见范围（公开 / 关注 / 屏蔽好友 / 私密），同一账号在微信读书 App 里可查。

「书评」在本任务中指阅读器已有的**热门想法**（点击热门划线弹出的他人点评），不是整本书评列表。

## Acceptance Criteria

- [ ] 点击划线（热门或自己的），弹出想法列表：先展示自己的想法，再展示热门想法；点赞图标可点，可切换赞 / 取消赞。列表默认不出现输入框。
- [ ] 点赞或取消赞成功后，同一账号在微信读书 App 对应想法上的赞状态一致。
- [ ] 想法列表底部有「写想法」；点开后才出现输入框，挂在当前划线 `range` 上；发送成功后新想法出现在当前列表顶部，输入框收起。
- [ ] 选中正文非空文本后，选区附近出现「写想法」；点开后可输入并发送，带上选中原文作为 `abstract`。发送成功后关闭选区工具条并 toast。
- [ ] 写想法时必须选择可见范围：公开 / 关注 / 屏蔽好友 / 私密。每次打开输入框都默认「屏蔽好友」（不记住上次选择）。输入区旁展示**当前将要发出的档**，列表里已有想法不打可见范围标签。空内容不可发送。
- [ ] 「屏蔽好友」使用微信读书官方能力（官方含义：仅未关注你的人可见），走官方接口字段与官方文案，不自造隐私模型。
- [ ] 发表成功后，同一账号在微信读书 App 的「我的想法」或对应划线想法中可查到该条，位置与所选原文一致；可见范围与发送时选择一致（屏蔽好友对应官方 `notVisibleToFriends`）。
- [ ] 发表成功后，插件正文能看到这条「我的划线」（来自想法自带 `range`），App 笔记划线里也能看到。切章再回来仍在。选区跨标签（如加粗、注释穿插）时同样能画出线。
- [ ] 未登录或 Cookie 失效时不假装成功，走现有登录失效提示。
- [ ] 点赞失败：该条赞数和已赞状态回到请求前。发表失败：输入内容保留。选区 `range` 无法按章节 HTML 偏移算出时禁止发送并提示换选一段。
- [ ] 不新增生产依赖。

## Edge Cases

- 想法列表为空：空态「暂无想法」，底部「写想法」按钮仍在；点按钮才出现输入框。
- 热门想法请求失败：空态 + 可重试，正文阅读不受影响。
- 点赞请求进行中：该条点赞控件禁用，避免连点。
- 选区映射不出与热门划线同一套 `range`：不发送。跨标签选区照常发送并画线（逐段包 `<span>`）。`range` 按注入热门划线 `<span>` **之前**的章节 HTML 偏移计算，避免挂错位置。
- 接口未返回当前用户是否已赞：按未赞展示，允许用户点赞；成功后以官方回包为准。
- 可见范围四档以官方 App 写想法选择器为准；实现时核对官方请求字段，不长期写死猜测字段名。

## Non-goals

- 整本书的公开书评列表、书评打星、书评入口。
- 修改或删除已发表想法，或事后改可见范围。
- 想法楼中楼回复。
- 只划线不写想法（没有想法正文时不单独提供划线按钮）。
- 给列表里每条已有想法打可见范围标签。
- 阅读时隐藏他人想法、屏蔽特定好友名单。
- 新的状态管理库或 npm 生产依赖。

## Constraints

- Webview 不直连微信读书；经 `WereadProvider` + `WeReadClient.execute` 带 Cookie 调用官方接口。
- 沿用现有热门想法 Popover 与 `WEREAD_*` 消息模式，不改为 Drawer。
- 发想法为划线想法（`type=1`），携带 `bookId`、`chapterUid`、`range`、`abstract`、正文、官方可见范围字段。官方划选写想法只打 `/web/review/add`，不另建 bookmark；划线是想法自带的 `range` 渲染出来的。阅读器按官方 `syncAllUserBookMark` 的口径，把 `bookmarklist`（我的划线）与 `/web/review/list?listType=11&mine=1`（我的想法）一起与热门划线合并后注入正文。
- 点划线拉想法列表时，按官方 `handleClickRange`：自己的想法（`/web/review/list?listType=11&mine=1`，range 相交）在前，热门 `readReviews` 在后。输入框只在点「写想法」后出现。
- 可见范围选择器与发送字段必须是官方四档，默认屏蔽好友。
- 点赞、发表的数据源是微信读书账号，不是插件本地假数据。
- 最小改动：只改阅读器想法相关 API、Provider 消息、阅读器 UI；不改书架、时长上报、状态栏。

## Notes

- 现有 `ReviewAccessibility` 只有私密 / 关注 / 公开，缺官方「屏蔽好友」，实现时按官方回包补齐映射。
- 现有 `web_review_add` 只覆盖整本书评 `type=4`，本任务扩展或并列划线想法 `type=1`。
- 热门想法已展示 `likesCount`，但点赞不可点，且无发表入口。
- 验收含手动：插件操作后打开微信读书 App 核对赞与想法（自动化测不到 App）。
